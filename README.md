# MysticEntityPlugin

Плагин для Paper/Spigot-серверов Minecraft (1.20.4), добавляющий атмосферные мистические явления в стиле городских легенд (Herobrine, Lucas, Error303, Null).

## Возможности
- Команда `/mystic start|stop|status`
- Команда `/mystic pulse [entity]` для ручного запуска явления
- Случайные «импульсы» по таймеру: частицы, звуки, сообщения игрокам
- Настраиваемые сущности и сообщения через `config.yml`

## Сборка
```bash
mvn clean package
```

Готовый jar будет в папке `target/`.
