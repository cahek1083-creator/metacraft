# MetaCraft PC AI Controller

Безопасное демо-приложение на Python, которое подключается к публичному AI API и помогает управлять ПК через подтверждаемые действия.

> ⚠️ Важно: приложение **не выполняет действия автоматически**. Нейросеть только предлагает JSON-план, а пользователь вручную подтверждает каждое действие в веб-интерфейсе. Это сделано специально, чтобы чужой API или ошибочный ответ модели не получил полный контроль над компьютером.

## Возможности

- Чат с нейросетью через публичный endpoint Pollinations `https://gen.pollinations.ai/v1/chat/completions`.
- Опциональный ключ `POLLINATIONS_API_KEY`; без ключа приложение всё равно пытается использовать публичный endpoint, но лимиты/доступность зависят от провайдера.
- Безопасные действия с ПК:
  - открыть URL в браузере;
  - открыть файл/папку или приложение;
  - показать список файлов в папке;
  - прочитать небольшой текстовый файл;
  - создать/перезаписать текстовый файл;
  - выполнить shell-команду только после подтверждения и только если она не похожа на опасную.
- Web UI на стандартной библиотеке Python — без обязательных зависимостей.
- Голосовое управление в браузере через Web Speech API: диктовка команды, автоотправка после распознавания и опциональная озвучка ответа.
- Локальный fallback-парсер, если AI API временно недоступен.

## Быстрый старт

```bash
python -m pc_ai_agent --host 127.0.0.1 --port 8765
```

Откройте в браузере:

```text
http://127.0.0.1:8765
```

## Настройка API

Pollinations рекомендует получить ключ на `enter.pollinations.ai`, но для прототипов часто доступен публичный endpoint.

```bash
export POLLINATIONS_API_KEY="pk_или_sk_ключ"
export PCAI_MODEL="openai"
python -m pc_ai_agent
```

Переменные окружения:

| Переменная | Значение по умолчанию | Описание |
| --- | --- | --- |
| `POLLINATIONS_API_KEY` | пусто | API-ключ Pollinations, если он есть. |
| `PCAI_MODEL` | `openai` | Модель для OpenAI-compatible endpoint. |
| `PCAI_API_BASE` | `https://gen.pollinations.ai/v1/chat/completions` | URL chat-completions API. |
| `PCAI_WORKSPACE` | текущая папка | Базовая папка для файловых действий. |

## Голосовое управление

1. Запустите приложение и откройте `http://127.0.0.1:8765` в браузере с поддержкой Web Speech API, например Chrome или Edge.
2. Нажмите **Начать запись** и разрешите доступ к микрофону.
3. Произнесите команду, например: `открой сайт https://example.com`.
4. Проверьте распознанный текст в поле запроса. Если включить чекбокс **отправлять после распознавания**, запрос автоматически уйдёт в AI после завершения записи.
5. При желании включите **озвучивать ответ**, чтобы браузер произносил ответ AI и результаты действий.

> Голос управляет только вводом команды. Исполнение действий по-прежнему требует отдельного подтверждения кнопкой **Выполнить это действие**.

## Как это работает

1. Пользователь пишет просьбу, например: `открой папку загрузок`.
2. Backend отправляет запрос нейросети и просит вернуть строго JSON с текстовым ответом и списком действий.
3. UI показывает предложенные действия.
4. Пользователь нажимает **Выполнить** для конкретного действия.
5. Backend валидирует действие, блокирует опасные команды и выполняет только подтверждённый пункт.

## Примеры запросов

- `Открой сайт https://example.com`
- Голосом: `покажи файлы в текущей папке`
- `Покажи файлы в текущей папке`
- `Создай файл notes/todo.txt с текстом "купить молоко"`
- `Открой калькулятор`
- `Выполни команду python --version`

## Ограничения безопасности

- Сервер по умолчанию слушает только `127.0.0.1`, не публикуйте его в интернет.
- Shell-команды проходят через denylist опасных паттернов (`rm -rf`, `shutdown`, `mkfs`, fork bomb и т.п.).
- Файловые операции ограничены рабочей папкой `PCAI_WORKSPACE`, кроме безопасного открытия существующих путей.
- Любое действие требует ручного подтверждения в UI.
- Для реального ежедневного использования лучше подключить локальную модель или API-ключ с понятными лимитами и политиками.
